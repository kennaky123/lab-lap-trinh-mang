3. Kiểm Tra Phương Thức HTTP GET / HEAD / POST

- GET: Nhận toàn bộ Header và Body tài nguyên của trang web hoặc tải tệp đa dịch vụ.

- HEAD: Chỉ nhận các dòng Header (Status Code, Content-Type, Content-Length) mà không tải Body.

- POST: Đẩy dữ liệu Form từ Client lên Server và lưu vào bảng Dữ Liệu Nhận Từ HTTP POST trên Server.
