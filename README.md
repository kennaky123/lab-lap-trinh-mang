# Lập trình mạng

Mở thư mục `D:\VScode\lap-trinh-mang` trong VS Code. Các bài sử dụng Python 3.10+ và Tkinter, không cần cài thư viện ngoài.

| Lab | Nội dung | Hướng dẫn |
| --- | --- | --- |
| 1. Chat Java Swing | Chat đa phương tiện (Broadcast, Multicast, Voice, Video, File, Database) bằng Java Swing | [chat-swing-app/README.md](chat-swing-app/README.md) |
| 2. FTP Java Swing | FTP Server (có CSDL người dùng & kiểm toán) + FTP Client (Giao diện FileZilla) | [ftp-swing-app/README.md](ftp-swing-app/README.md) |
| 3. Mail Java Swing | Mail Server (SMTP 2525 & POP3 1110 có CSDL) + Gmail Client (Localhost & Gmail Thật) | [mail-swing-app/README.md](mail-swing-app/README.md) |
| 4. Web Java Swing | Web Server (Đa dịch vụ .pdf, .mp3, .mp4) + Web Browser Client (Chrome / Cốc Cốc) | [web-swing-app/README.md](web-swing-app/README.md) |
| 5. RMI Sync Java Swing | RMI Đồng bộ hóa dữ liệu 2 Server (Active-Active 2-Way Sync) trên 2 máy thực & máy ảo | [rmi-sync-app/README.md](rmi-sync-app/README.md) |
| Lab 4 | Chat và truyền file P2P / Client–Server kết hợp (Python) | [DangQuocToan-ITB200-4/README.md](DangQuocToan-ITB200-4/README.md) |
| Lab 5 — Bài 1 | ExchangeRateServer và ExchangeRateTable (Python) | [lab-5/README.md](lab-5/README.md) |
| Lab 5 — Bài 2 | Mail Server và Mail Client (Python) | [lab-5/README.md](lab-5/README.md) |

Chạy nhanh bằng các file `.bat` trong từng lab hoặc dùng lệnh terminal theo hướng dẫn. Nếu Windows dùng lệnh `py` thay vì `python`, thay tên lệnh tương ứng trong terminal hoặc file `.bat`.
